# Validation

Validated against the Home Assistant Core 2026.10.0 package on macOS on October 27, 2026.

- Python suite: 35 tests pass their assertions, including native scene create/replace/delete services, state events, saved settings, and a real forwarded switch platform, setup/options scene scope selection, label creation and selection, live label assignment/removal, and switch registry cleanup when scope changes.
- Scene picker: verified combined name search, monitoring-scope filtering, area and no-area filtering, and the empty state in the browser preview. Backend coverage includes live area assignment, rename, device inheritance, deletion, and monitoring-scope metadata. `scene-picker-preview.png` shows the updated picker with synthetic scenes.
- Frontend JavaScript syntax check and Python byte compilation pass.
- Tabbed layout: Scene Config and Global Config are page-level tabs; Scene Config now contains scene navigation on the left and Configuration/Compare/Debug subtabs on the right. Browser preview verified independent arrow-key navigation and wrapping in both tab groups, saving global settings, retaining the active scene subtab across page changes, and retaining an unsaved scene tolerance across page changes and a mock live settings update. Earlier verification also covered filtering, scene selection, and scene-tolerance saves updating comparisons. `page-tabs-preview.png` shows the global page. JavaScript syntax check passes.
- Attribute checkboxes: browser preview verified saving an unchecked attribute, restoring the exclusion after switching scenes, separate attribute lists per scene, and disabling/re-enabling individual choices with **Ignore all attributes**. The mock connection's live update after saving preserves the choices. `attribute-checkbox-preview.png` shows the updated scene settings. JavaScript syntax check passes.
- Browser preview: verified the differences table, saving a scene tolerance, switching between scenes, and activation clearing differences through a mock Home Assistant connection. `panel-preview.png` shows the original UI with synthetic entities, captured before the component was renamed to Stateful Scenes Revisited.
- The install archive contains only integration source/assets and can be extracted under `/config`.

The local pytest process segfaults during interpreter shutdown **after** reporting passing tests. It reproduces with both Python 3.14.2 and 3.14.10, and also with a minimal native Home Assistant scene test importing `homeassistant.components.frontend`, without importing this integration. A native scene smoke test outside pytest exits successfully. The cause has not been diagnosed, so this is not a clean passing test process. The included Linux CI workflow has not been run remotely.

No production Home Assistant instance or physical devices were modified. Actual installation and device-specific scene reproduction remain to be verified on the target instance. Third-party opaque scenes cannot be compared without a provider exposing their targets.
